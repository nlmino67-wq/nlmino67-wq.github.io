04 — Process

How I build AI video

Custom ComfyUI pipelines on my own RTX 4090, run from a studio app I built so a team can use them. Local by default; Kling 3.0 through the Kie API when a shot needs it.

The stack

Video
MiniMax H3 · LTX 2.5 · Wan 2.2
Image
Krea 2 · Qwen-Image-Edit · Z-Image
Voice & audio
Qwen3-TTS · IndexTTS-2 · Kokoro · ACE-Step · faster-whisper
Language
Gemma on Ollama
Cloud, when needed
Kling 3.0 via the Kie API
Hardware
My own RTX 4090

What that gets you

  • The same face in every shot. One photo becomes a four-view character sheet.
  • Your real logo, exact. The brand mark is put back onto generated products.
  • Talking heads past a minute. Segments chained with no visible seam.
  • Checked before the edit. Every clip is checked for face and logo accuracy.
